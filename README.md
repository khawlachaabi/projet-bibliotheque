# Gestion Bibliothèque IHEC

Application de gestion de bibliothèque pour l'IHEC, permettant d'administrer les livres, les emprunts et les utilisateurs via une interface de bureau.

## ✨ Fonctionnalités

- Gestion du catalogue de livres (ajout, modification, suppression)
- Gestion des étudiants / lecteurs
- Suivi des emprunts et retours
- Consultation rapide des disponibilités
- Captures d'écran disponibles dans le dossier `Capture`

## 🛠️ Technologies

- Application desktop Windows (`.exe`)
- Base de données locale (par ex. fichier / SGBD – selon implémentation)
- Langage : [à compléter, ex : C#, Java, etc.]

## 🚀 Installation & exécution

1. Cloner le dépôt :
   ```bash
   git clone https://github.com/khawlachaabi/P2.git
   cd P2
   ```
2. Sur Windows, double-cliquer sur :
   - `gestion biblio ihec.exe`

> Si un antivirus bloque l'exécutable, le lancer en tant qu'administrateur ou ajouter une exception.
